# 特殊ボーリング工業株式会社 コーポレートサイト

外部ライブラリに依存しない HTML / CSS / Vanilla JavaScript 製の
コーポレートサイトです（Google Fonts のみ利用）。

## 公開サイト

GitHub Pages で公開しています。

**https://skawashin1122.github.io/boring-site/**

`main` ブランチの内容がそのまま反映されます。`main` に push すると
数分以内に自動で再デプロイされます。

## ファイル構成

```
index.html
css/style.css
js/main.js
images/README.txt
```

## ローカルでの確認方法

```bash
python3 -m http.server 8123
```

起動後、ブラウザで `http://localhost:8123` を開いてください。

## 実装済みの機能

- ハンバーガーメニュー（`aria-expanded` 制御、Escキーで閉じる）
- スムーススクロール（ヘッダー高さ分オフセット）
- スクロールによるフェードインアニメーション（`prefers-reduced-motion` 対応）
- 現在セクションのナビハイライト
- ページトップボタンの表示切替
- フォームのクライアントサイドバリデーション（`aria-invalid` 制御）
- 480 / 768 / 1024px のブレイクポイントでのレイアウト
- `tel:` リンクによるスマートフォンでのタップ発信
