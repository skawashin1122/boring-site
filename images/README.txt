画像差し替えガイド
==================

現在、写真素材が未提供のため、サイト内の画像枠はCSSグラデーション等の
プレースホルダで代用しています。実際の写真が用意でき次第、以下のサイズを
目安に差し替えてください。

1. favicon
   - ファイル名: favicon.ico
   - サイズ: 32x32px（16x16pxを含むマルチサイズ推奨）
   - 配置: images/favicon.ico
   - index.html の <!-- <link rel="icon" ... --> のコメントを解除して有効化

2. OGP画像（SNSシェア時に表示）
   - ファイル名: ogp.jpg
   - サイズ: 1200x630px
   - 配置: images/ogp.jpg
   - index.html の <meta property="og:image" ...> のコメントを解除して有効化

3. ヒーロー背景写真（任意）
   - 推奨サイズ: 1920x1080px以上、横長
   - 内容例: 掘削作業の様子、施工現場、井戸設備など
   - 配置後、css/style.css の .hero に background-image を追加

4. 事業内容カード用アイコン／写真（任意で差し替え可能）
   - 現在はインラインSVGアイコンを使用（差し替え不要）
   - 実際の施工写真に変更する場合は 400x300px 程度を推奨

備考:
- すべての画像には内容を説明する alt 属性を必ず設定してください。
- 写真は撮影・使用許諾が確認できたものだけを使用してください。
